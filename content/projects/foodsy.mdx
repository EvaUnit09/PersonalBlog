A real-time social dining coordination app that solves the "where should we eat?" problem for groups. Create a session, invite friends with a join code, and vote on nearby restaurants together.

Restaurant data is aggregated from Google Places and Foursquare. Voting updates live over STOMP WebSockets. Auth is Google OAuth2 with JWT. The frontend is React and Next.js on Vercel; the backend is Spring Boot and PostgreSQL on AWS EC2 and RDS.
